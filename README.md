# zkMaze Vanilla Version

This is a simplified version of the zkMaze game using only vanilla HTML, CSS, and JavaScript.

## How to Play

1. Download all the files in this directory to your computer
2. Simply open the `index.html` file in your web browser
3. No server or installation needed!

## Game Controls

- Use arrow keys or WASD to move
- Use the on-screen buttons to control the game
- Navigate through the maze to find the exit
- Once at the exit, verify your solution

## About Zero-Knowledge Proofs

This simplified version simulates the verification process. In the full version, we use Succinct SP1 for actual zero-knowledge proof generation.

## Files Included

- `index.html` - The main HTML file
- `styles.css` - Styling for the game
- `maze.js` - Maze generation and utility functions
- `game.js` - Game logic and control
- `favicon.svg` - Game icon

## Note

This version works completely offline and doesn't require a server or any dependencies.
